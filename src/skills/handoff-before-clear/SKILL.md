# Handoff before clear
After a clear, only files, memory and skills survive. Anything that lives only in chat is lost.
1. **Write one note** in the project folder: `Session Handoff YYYY-MM-DD.md`, with a status line and the date.
2. **Sections:** 0 one screen (state, what is running, what to do after the clear); 1 questions waiting for the user, as a table with a default for each; 2 plans, as links to the files that hold them (never copy a plan in); 3 any task in progress: the request in the user's own words, sources, route, and a result block to fill at the end; 4 other open threads; 5 the first moves after the clear (4 lines).
3. **Finish the running task,** then rewrite the result block as DONE or PENDING per item, with the exact command the user must run for anything left, and fix section 0. A stale "in progress" makes the next session redo the work.
4. **Check:** every link resolves, no keys or secrets, absolute dates.
5. **Do not** paste whole plans into the handoff, include private material, or commit and push unless the user says. List the exact paths to stage so "commit" is one word later.
